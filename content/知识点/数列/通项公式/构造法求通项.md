## 类型一：$a_{n+1} = pa_n + q$

设 $a_{n+1} + \lambda = p(a_n + \lambda)$，解得 $\lambda = \dfrac{q}{p-1}$（$p \neq 1$）

则 $\{a_n + \lambda\}$ 是等比数列。

## 类型二：$a_{n+1} = pa_n + qn + r$

设 $a_{n+1} + k(n+1) + b = p(a_n + kn + b)$，待定系数求 $k, b$

## 类型三：$a_{n+1} = pa_n + q^n$

两边同除以 $p^{n+1}$ 或 $q^{n+1}$ 转化为可累加的形式。

## 典型例题

**例**：$a_1 = 1$，$a_{n+1} = 2a_n + 3$，求 $a_n$

> 设 $a_{n+1} + \lambda = 2(a_n + \lambda)$  
> $a_{n+1} = 2a_n + \lambda$，$\lambda = 3$  
> $a_n + 3 = (a_1 + 3)2^{n-1} = 4 \cdot 2^{n-1} = 2^{n+1}$  
> $a_n = 2^{n+1} - 3$
