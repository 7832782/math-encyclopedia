## 定义

$a_{n+1} - a_n = d$（$d$ 为常数，叫公差）

## 核心公式

| 项目 | 公式 |
|------|------|
| **通项公式** | $a_n = a_1 + (n-1)d$ |
| **前 $n$ 项和** | $S_n = \dfrac{n(a_1 + a_n)}{2} = na_1 + \dfrac{n(n-1)}{2}d$ |

## 重要性质

| 性质 | 内容 |
|------|------|
| 等差中项 | $a, A, b$ 成等差 ⇔ $2A = a + b$ |
| 下标和 | $m + n = p + q \Rightarrow a_m + a_n = a_p + a_q$ |
| 片段和 | $S_n$、$S_{2n} - S_n$、$S_{3n} - S_{2n}$ 也成等差 |
| 奇偶项 | 项数 $2n$：$S_{\text{偶}} - S_{\text{奇}} = nd$ |

## 典型例题

**例**：[[知识点/数列/数列基础/等差数列|等差数列]] $\{a_n\}$ 中，$a_1 = 2$，$a_5 = 10$，求 $S_6$

> $d = \dfrac{a_5 - a_1}{4} = \dfrac{8}{4} = 2$  
> $S_6 = 6 \times 2 + \dfrac{6 \times 5}{2} \times 2 = 12 + 30 = 42$
