## 常见题型

### 1. 证明 $a_n$ 的有界性

利用单调性 + 首项范围证明所有项在某范围内。

### 2. 放缩法求和

将通项放大或缩小后转化为可求和的形式：

- $\dfrac{1}{n^2} < \dfrac{1}{n(n-1)} = \dfrac{1}{n-1} - \dfrac{1}{n}$
- $\dfrac{1}{n^2} > \dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$

### 3. 先求和后放缩

先求出精确和，再进行不等式放缩。

## 典型思路

- 求通项 → 放缩 → 求和 → 得证
- 求通项 → 求和 → 放缩 → 得证

## 典型例题

**例**：证明：$\dfrac{1}{1^2} + \dfrac{1}{2^2} + \dots + \dfrac{1}{n^2} < 2$

> $\dfrac{1}{k^2} < \dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$（$k \geq 2$）  
> $S_n < 1 + (1 - \dfrac{1}{2}) + (\dfrac{1}{2} - \dfrac{1}{3}) + \dots + (\dfrac{1}{n-1} - \dfrac{1}{n})$  
> $= 2 - \dfrac{1}{n} < 2$
