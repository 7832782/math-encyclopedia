## 正弦曲线 $y = \sin x$

```
y
1┤╭─╮    ╭─╮    ╭─╮
0┤╯ ╰────╯ ╰────╯ ╰──→ x
-1┤          π   2π
  0    π/2      3π/2
```

- 过原点
- 一个周期 $[0, 2\pi]$ 内的五个关键点：$(0,0)$、$(\dfrac{\pi}{2}, 1)$、$(\pi, 0)$、$(\dfrac{3\pi}{2}, -1)$、$(2\pi, 0)$

## 余弦曲线 $y = \cos x$

```
y
1┤╭─╮  ╭───╮  ╭───╮
0┤╯  ╰─╯   ╰─╯   ╰──→ x
-1┤          π   2π
  0    π/2      3π/2
```

- 与 $\sin x$ 形状相同，向左平移 $\dfrac{\pi}{2}$
- $\cos x = \sin(x + \dfrac{\pi}{2})$

## 正切曲线 $y = \tan x$

```
y
│  ╱│  ╱│
0──╲─┼─╲─┼──→ x
│   ╲│  ╲│
```

- 有垂直渐近线 $x = \dfrac{\pi}{2} + k\pi$
- 以 $\pi$ 为周期，在每个区间 $(-\dfrac{\pi}{2}+k\pi, \dfrac{\pi}{2}+k\pi)$ 内递增

## "五点法"作图

画 $y = \sin x$ 或 $y = \cos x$ 在一个周期内的草图时，找准五个关键点的坐标即可。

## 典型例题

**例**：用五点法画出 $y = \sin x$ 在 $[0, 2\pi]$ 上的图象

> 取五个点：$(0,0)$、$(\dfrac{\pi}{2},1)$、$(\pi,0)$、$(\dfrac{3\pi}{2},-1)$、$(2\pi,0)$，光滑曲线连接。
