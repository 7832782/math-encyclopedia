## 定理内容

在 $\triangle ABC$ 中，$a, b, c$ 分别为 $A, B, C$ 的对边，则：

$$\boxed{\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R}$$

其中 $R$ 为 $\triangle ABC$ **外接圆的半径**。

## 适用情形

| 已知条件 | 可解决的问题 |
|---------|-------------|
| 两角一边 (AAS, ASA) | 求其他边和角 |
| 两边一对角 (SSA) | 可能有两解、一解或无解 |

### SSA 解的个数

已知 $a, b, A$：

| 条件 | 解的情况 |
|------|---------|
| $A \geq 90^\circ$ 且 $a > b$ | 一解 |
| $A \geq 90^\circ$ 且 $a \leq b$ | 无解 |
| $A < 90^\circ$ 且 $a = b\sin A$ | 一解（直角） |
| $A < 90^\circ$ 且 $b\sin A < a < b$ | 两解 |
| $A < 90^\circ$ 且 $a \geq b$ | 一解 |
| $A < 90^\circ$ 且 $a < b\sin A$ | 无解 |

## 典型例题

**例**：$\triangle ABC$ 中，$A = 30^\circ$，$B = 45^\circ$，$a = 10$，求 $b$

> [!details]- 解答
> $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$  
> $\dfrac{10}{\sin 30^\circ} = \dfrac{b}{\sin 45^\circ}$  
> $b = \dfrac{10 \times \dfrac{\sqrt{2}}{2}}{\dfrac{1}{2}} = 10\sqrt{2}$
