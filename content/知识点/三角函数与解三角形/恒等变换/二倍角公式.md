## 核心公式

由和角公式中令 $\beta = \alpha$ 可得：

### 正弦

$$\sin 2\alpha = 2\sin \alpha \cos \alpha$$

### 余弦

$$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha$$
$$\phantom{\cos 2\alpha} = 2\cos^2 \alpha - 1$$
$$\phantom{\cos 2\alpha} = 1 - 2\sin^2 \alpha$$

### 正切

$$\tan 2\alpha = \dfrac{2\tan \alpha}{1 - \tan^2 \alpha}$$

## 降幂公式（重要！）

由 $\cos 2\alpha = 2\cos^2 \alpha - 1$ 和 $\cos 2\alpha = 1 - 2\sin^2 \alpha$ 反解得：

$$\boxed{\sin^2 \alpha = \dfrac{1 - \cos 2\alpha}{2}} \qquad \boxed{\cos^2 \alpha = \dfrac{1 + \cos 2\alpha}{2}}$$

> [!important] 降幂公式是高考高频工具，用于将二次降为一次

## 辅助角公式

$$a\sin x + b\cos x = \sqrt{a^2 + b^2} \sin(x + \varphi)$$

其中 $\sin \varphi = \dfrac{b}{\sqrt{a^2 + b^2}}$，$\cos \varphi = \dfrac{a}{\sqrt{a^2 + b^2}}$

## 典型例题

**例**：化简 $f(x) = \sin x \cos x + \cos^2 x$

> [!details]- 解答
> $\sin x \cos x = \dfrac{1}{2}\sin 2x$  
> $\cos^2 x = \dfrac{1 + \cos 2x}{2}$  
> $f(x) = \dfrac{1}{2}\sin 2x + \dfrac{1}{2}\cos 2x + \dfrac{1}{2}$  
> $= \dfrac{\sqrt{2}}{2}\sin(2x + \dfrac{\pi}{4}) + \dfrac{1}{2}$
