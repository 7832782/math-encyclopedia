## 定义

**焦点弦**：过圆锥曲线焦点的弦。

**通径**：过焦点且垂直于长轴（椭圆）或实轴（双曲线、抛物线）的焦点弦，是所有焦点弦中最短（椭圆、双曲线）或唯一确定长度（抛物线）的特殊焦点弦。

## 椭圆的焦点弦

### 焦点弦长公式

设椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$），焦点 $F(c, 0)$，过 $F$ 的弦 $AB$ 的倾斜角为 $\alpha$。

**焦点弦长公式**：

$$|AB| = \dfrac{2ab^2}{a^2 - c^2\cos^2\alpha} = \dfrac{2ab^2}{b^2 + c^2\sin^2\alpha}$$

### 通径

**定义**：过焦点且垂直于长轴的弦。

**长度**：$|AB| = \dfrac{2b^2}{a}$

**推导**：当 $\alpha = 90°$ 时，$\sin\alpha = 1$，代入公式得 $|AB| = \dfrac{2ab^2}{b^2+c^2} = \dfrac{2ab^2}{a^2} = \dfrac{2b^2}{a}$。

### 焦点弦的最值

**最长**：当 $\alpha = 0°$ 时，焦点弦为长轴，长度 $2a$。

**最短**：当 $\alpha = 90°$ 时，焦点弦为通径，长度 $\dfrac{2b^2}{a}$。

## 双曲线的焦点弦

### 焦点弦长公式

设双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$，焦点 $F(c, 0)$，过 $F$ 的弦 $AB$ 的倾斜角为 $\alpha$。

**焦点弦长公式**：

$$|AB| = \dfrac{2ab^2}{|a^2 - c^2\cos^2\alpha|} = \dfrac{2ab^2}{|b^2 - c^2\sin^2\alpha|}$$

> [!warning] 注意
> 双曲线的焦点弦可能在同一支上，也可能跨两支，需要分类讨论。

### 通径

**长度**：$|AB| = \dfrac{2b^2}{a}$

## 抛物线的焦点弦

### 焦点弦长公式

设抛物线 $y^2 = 4px$（$p > 0$），焦点 $F(p, 0)$，过 $F$ 的弦 $AB$ 的倾斜角为 $\alpha$（$\alpha \neq 0$）。

**焦点弦长公式**：

$$|AB| = \dfrac{4p}{\sin^2\alpha}$$

### 焦半径公式

设 $A(x_1, y_1)$ 在抛物线 $y^2 = 4px$ 上，则**焦半径**：

$$|AF| = x_1 + p$$

**焦点弦长**（设 $A(x_1, y_1), B(x_2, y_2)$）：

$$|AB| = |AF| + |BF| = x_1 + x_2 + 2p$$

### 通径

**长度**：$|AB| = 4p$（当 $\alpha = 90°$ 时，$\sin\alpha = 1$）

**性质**：抛物线的通径是所有焦点弦中最短的。

### 抛物线焦点弦的重要性质

设抛物线 $y^2 = 4px$ 的焦点弦 $AB$，端点 $A(x_1, y_1), B(x_2, y_2)$。

**性质 1**：$y_1 \cdot y_2 = -4p^2$（定值）

**性质 2**：$x_1 \cdot x_2 = p^2$（定值）

**性质 3**：以 $AB$ 为直径的圆与准线相切。

**性质 4**：$\dfrac{1}{|AF|} + \dfrac{1}{|BF|} = \dfrac{1}{p}$（调和性质）

**性质 5**：$|AB| = x_1 + x_2 + 2p$，且 $x_1 + x_2 \geq 2p$（由性质 2 和均值不等式），故 $|AB| \geq 4p$。

## 典型例题

**例 1**：抛物线 $y^2 = 8x$ 的焦点弦 $AB$ 的端点坐标为 $A(2, 4)$ 和 $B(\dfrac{1}{2}, -2)$，求 $|AB|$。

> $y^2 = 8x$，则 $4p = 8$，$p = 2$，焦点 $F(2, 0)$
>
> 验证：$A(2, 4)$ 在抛物线上（$4^2 = 16 = 8 \times 2$ ✓）
>
> $B(\dfrac{1}{2}, -2)$ 在抛物线上（$(-2)^2 = 4 = 8 \times \dfrac{1}{2}$ ✓）
>
> 焦半径：$|AF| = 2 + 2 = 4$，$|BF| = \dfrac{1}{2} + 2 = \dfrac{5}{2}$
>
> $|AB| = 4 + \dfrac{5}{2} = \dfrac{13}{2}$
>
> 或直接用公式：$|AB| = x_1 + x_2 + 2p = 2 + \dfrac{1}{2} + 4 = \dfrac{13}{2}$

**例 2**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 的焦点弦 $AB$ 过焦点 $F$，倾斜角为 $45°$，求 $|AB|$。

> $a = 2$，$b = 1$，$c = \sqrt{3}$
>
> $\alpha = 45°$，$\sin\alpha = \dfrac{\sqrt{2}}{2}$，$\sin^2\alpha = \dfrac{1}{2}$
>
> $|AB| = \dfrac{2ab^2}{b^2+c^2\sin^2\alpha} = \dfrac{2 \times 2 \times 1}{1 + 3 \times \dfrac{1}{2}} = \dfrac{4}{\dfrac{5}{2}} = \dfrac{8}{5}$

**例 3**：抛物线 $y^2 = 4x$ 的焦点弦 $AB$ 的中点到准线的距离为 $3$，求 $|AB|$。

> 抛物线 $y^2 = 4x$，$p = 1$，准线 $x = -1$，焦点 $F(1, 0)$
>
> 设 $A(x_1, y_1), B(x_2, y_2)$，中点 $M\left(\dfrac{x_1+x_2}{2}, \dfrac{y_1+y_2}{2}\right)$
>
> 中点到准线的距离：$\dfrac{x_1+x_2}{2} + 1 = 3$，故 $x_1 + x_2 = 4$
>
> $|AB| = x_1 + x_2 + 2p = 4 + 2 = 6$

## 焦点弦与焦半径的关系

**焦半径**：曲线上一点到焦点的距离。

**焦点弦**：过焦点的弦，由两条焦半径组成。

| 曲线类型                                   | 焦半径公式 | 焦点弦公式 |
| ------------------------------------------ | ---------- | ---------- | ---------------------------- | ----------------------------------------- | --- | --------------------------------------- |
| 椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$   | $          | PF         | = a - ex_0$（$P(x_0, y_0)$） | $\dfrac{2ab^2}{a^2-c^2\cos^2\alpha}$       |
| 双曲线 $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$ | $          | PF         | =                            | a - ex_0                                  | $   | $\dfrac{2ab^2}{\|a^2-c^2\cos^2\alpha\|}$ |
| 抛物线 $y^2=4px$                           | $          | PF         | = x_0 + p$                   | $x_1+x_2+2p$ 或 $\dfrac{4p}{\sin^2\alpha}$ |
