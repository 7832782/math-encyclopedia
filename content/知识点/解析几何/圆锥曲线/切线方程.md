## 定义

**切线**：与圆锥曲线有且只有一个公共点，且与曲线在该点"相切"的直线。

## 椭圆的切线方程

### 点在椭圆上

设椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$，点 $P(x_0, y_0)$ 在椭圆上。

**切线方程**（替换法则）：

$$\dfrac{x_0 x}{a^2} + \dfrac{y_0 y}{b^2} = 1$$

**推导思路**：将椭圆方程中 $x^2$ 换成 $x_0 x$，$y^2$ 换成 $y_0 y$，常数项不变。

**例**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上一点 $P(\sqrt{2}, \dfrac{\sqrt{2}}{2})$，求切线方程。

> 切线方程：$\dfrac{\sqrt{2}x}{4} + \dfrac{\sqrt{2}y}{2} = 1$
>
> 化简：$\dfrac{x}{2\sqrt{2}} + \dfrac{y}{\sqrt{2}} = 1$
>
> 即 $x + 2y = 2\sqrt{2}$

### 切点弦方程

过椭圆外一点 $P(x_0, y_0)$ 作椭圆的两条切线，切点为 $A, B$，则切点弦 $AB$ 的方程为：

$$\dfrac{x_0 x}{a^2} + \dfrac{y_0 y}{b^2} = 1$$

（形式上与切线方程相同）

## 双曲线的切线方程

### 点在双曲线上

设双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$，点 $P(x_0, y_0)$ 在双曲线上。

**切线方程**：

$$\dfrac{x_0 x}{a^2} - \dfrac{y_0 y}{b^2} = 1$$

### 渐近线与切线

双曲线的切线与渐近线有特殊关系：

- 双曲线的切线与渐近线围成的三角形面积为定值（$ab$）

## 抛物线的切线方程

### 点在抛物线上

设抛物线 $y^2 = 4px$，点 $P(x_0, y_0)$ 在抛物线上。

**切线方程**：

$$y_0 y = 2p(x + x_0)$$

或写成斜截式：

$$y = \dfrac{2p}{y_0}x + \dfrac{2px_0}{y_0}$$

**斜率**：$k = \dfrac{2p}{y_0} = \dfrac{y_0}{2x_0}$

**例**：抛物线 $y^2 = 8x$ 上一点 $P(2, 4)$，求切线方程。

> $y^2 = 8x$，$4p = 8$，$p = 2$
>
> 切线方程：$4y = 4(x + 2)$
>
> 即 $y = x + 2$

### 过抛物线外一点的切线

设抛物线 $y^2 = 4px$，点 $P(x_0, y_0)$ 在抛物线外（$y_0^2 > 4px_0$）。

**切线方程**：设切线方程为 $y = kx + m$，代入抛物线方程，判别式为 0，解出 $k$ 和 $m$。

## 切线的几何性质

### 椭圆的光学性质

**定理**：从椭圆一个焦点发出的光线，经椭圆反射后，必经过另一个焦点。

**数学表述**：过椭圆上一点 $P$ 的切线与 $PF_1, PF_2$ 的夹角相等。

**应用**：激光器、耳语廊、行星轨道等。

### 双曲线的光学性质

**定理**：从双曲线一个焦点发出的光线，经双曲线反射后，看起来像从另一个焦点发出。

**数学表述**：过双曲线上一点 $P$ 的切线平分 $\angle F_1PF_2$ 的外角。

### 抛物线的光学性质

**定理**：从抛物线焦点发出的光线，经抛物线反射后平行于抛物线的轴。

**数学表述**：过抛物线上一点 $P$ 的切线与 $PF$ 的夹角，等于切线与轴的夹角。

**应用**：卫星天线、探照灯、太阳能聚光器。

## 典型例题

**例 1**：椭圆 $\dfrac{x^2}{9} + \dfrac{y^2}{4} = 1$ 上一点 $P$ 到两个焦点 $F_1, F_2$ 的距离分别为 2 和 4，求点 $P$ 处的切线方程。

> 由椭圆定义：$|PF_1| + |PF_2| = 2a = 6$
>
> 题给 $|PF_1| + |PF_2| = 2 + 4 = 6$ ✓
>
> $a = 3$，$b = 2$，$c = \sqrt{5}$
>
> 设 $P(x_0, y_0)$，由焦半径公式：
>
> - $|PF_1| = a + ex_0$，$2 = 3 + \dfrac{\sqrt{5}}{3}x_0$
> - 解得 $x_0 = -\dfrac{3}{\sqrt{5}}$
>
> 代入椭圆方程：$\dfrac{9/5}{9} + \dfrac{y_0^2}{4} = 1$
>
> $\dfrac{y_0^2}{4} = \dfrac{4}{5}$，$y_0^2 = \dfrac{16}{5}$，$y_0 = \pm\frac{4}{\sqrt{5}}$
>
> 切线方程：$\dfrac{-\dfrac{3}{\sqrt{5}}x}{9} + \dfrac{\pm\frac{4}{\sqrt{5}}y}{4} = 1$
>
> 即 $-\dfrac{x}{3\sqrt{5}} \pm \dfrac{y}{\sqrt{5}} = 1$
>
> 化简：$\mp x + 3y = 3\sqrt{5}$ 或 $\pm x - 3y = 3\sqrt{5}$

**例 2**：求过点 $P(3, 4)$ 且与抛物线 $y^2 = 4x$ 相切的直线方程。

> $y^2 = 4x$，$p = 1$
>
> 验证：$4^2 = 16 \neq 4 \times 3 = 12$，点 $P$ 在抛物线外。
>
> 设切线方程为 $y - 4 = k(x - 3)$，即 $y = kx - 3k + 4$
>
> 代入 $y^2 = 4x$：$(kx - 3k + 4)^2 = 4x$
>
> $k^2x^2 - 2k(3k-4)x + (3k-4)^2 - 4x = 0$
>
> $k^2x^2 - (6k^2 - 8k + 4)x + (3k-4)^2 = 0$
>
> 判别式为 0：$(6k^2 - 8k + 4)^2 - 4k^2(3k-4)^2 = 0$
>
> 解得 $k = 1$ 或 $k = \dfrac{1}{3}$
>
> 切线方程：$y = x + 1$ 或 $y = \dfrac{1}{3}x + 3$

**例 3**：证明椭圆上一点的切线平分该点与两焦点连线的夹角的外角。

> 设椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 上一点 $P(x_0, y_0)$
>
> 切线方程：$\dfrac{x_0 x}{a^2} + \dfrac{y_0 y}{b^2} = 1$
>
> 斜率：$k = -\dfrac{b^2 x_0}{a^2 y_0}$
>
> 利用向量夹角公式或距离公式可证明光学性质。

## 切线方程的统一记忆法

对于椭圆、双曲线，切线方程可统一用"替换法"记忆：

$$\dfrac{x^2}{a^2} \pm \dfrac{y^2}{b^2} = 1 \quad \xrightarrow{\text{切线方程}} \quad \dfrac{x_0 x}{a^2} \pm \dfrac{y_0 y}{b^2} = 1$$

对于抛物线：

$$y^2 = 4px \quad \xrightarrow{\text{切线方程}} \quad y_0 y = 2p(x + x_0)$$
