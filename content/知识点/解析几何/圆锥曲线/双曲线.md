## 定义

平面内到两个定点 $F_1, F_2$ 的距离之差的绝对值为常数 $2a$ 的点的轨迹。

$$||PF_1| - |PF_2|| = 2a < |F_1F_2| = 2c$$

## 标准方程与性质

| | 焦点在 $x$ 轴 | 焦点在 $y$ 轴 |
|:--|:---|:---|
| **标准方程** | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ | $\dfrac{y^2}{a^2} - \dfrac{x^2}{b^2} = 1$ |
| **顶点** | $(\pm a, 0)$ | $(0, \pm a)$ |
| **焦点** | $(\pm c, 0)$ | $(0, \pm c)$ |
| **渐近线** | $y = \pm \dfrac{b}{a}x$ | $y = \pm \dfrac{a}{b}x$ |
| **离心率** | $e = \dfrac{c}{a} \in (1, +\infty)$ | 同上 |

## 重要关系

$$c^2 = a^2 + b^2 \quad \text{（$c$ 最大！）}$$

## 椭圆与双曲线对比

| | [[知识点/解析几何/圆锥曲线/椭圆|椭圆]] | [[知识点/解析几何/圆锥曲线/双曲线|双曲线]] |
|:--|:---|:------|
| 关系式 | $a^2 = b^2 + c^2$ | $c^2 = a^2 + b^2$ |
| $e$ | $(0, 1)$ | $(1, +\infty)$ |
| 图形 | 封闭曲线 | 两支开放曲线 |

## 典型例题

**例**：[[知识点/解析几何/圆锥曲线/双曲线|双曲线]] $\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1$，求 $a, b, c$ 和离心率、渐近线

> $a^2 = 16 \Rightarrow a = 4$，$b^2 = 9 \Rightarrow b = 3$  
> $c^2 = a^2 + b^2 = 25 \Rightarrow c = 5$  
> $e = \dfrac{c}{a} = \dfrac{5}{4}$  
> 渐近线：$y = \pm \dfrac{3}{4}x$
