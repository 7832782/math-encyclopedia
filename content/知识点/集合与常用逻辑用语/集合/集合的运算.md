## 定义

### 交集 $\cap$

$$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$$

两个集合的**公共元素**组成的集合。

### 并集 $\cup$

$$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$$

两个集合的**所有元素**合并而成（重复元素只算一次）。

### 补集 $\complement_U A$

若 $A \subseteq U$（$U$ 为全集），则

$$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$$

在全集 $U$ 中**不属于** $A$ 的元素。

## 运算律

| 名称 | 公式 |
|------|------|
| **交换律** | $A \cap B = B \cap A$，$A \cup B = B \cup A$ |
| **结合律** | $(A \cap B) \cap C = A \cap (B \cap C)$，$(A \cup B) \cup C = A \cup (B \cup C)$ |
| **分配律** | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$，$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ |
| **德·摩根律** | $\complement_U (A \cap B) = (\complement_U A) \cup (\complement_U B)$，$\complement_U (A \cup B) = (\complement_U A) \cap (\complement_U B)$ |
| **吸收律** | $A \cap (A \cup B) = A$，$A \cup (A \cap B) = A$ |
| **同一律** | $A \cap U = A$，$A \cup \varnothing = A$ |
| **零律** | $A \cap \varnothing = \varnothing$，$A \cup U = U$ |
| **排中律** | $A \cap (\complement_U A) = \varnothing$，$A \cup (\complement_U A) = U$ |
| **双重否定** | $\complement_U (\complement_U A) = A$ |

> [!tip] 德·摩根律记忆口诀
> "交的补 = 补的并，并的补 = 补的交"——长杠变短杠，符号取反

## 与集合关系的关系

| 条件 | 等价关系 |
|------|---------|
| $A \subseteq B$ | $A \cap B = A$，$A \cup B = B$ |
| $A \cap B = \varnothing$ | $A$ 与 $B$ **不相交**（无公共元素） |

## 典型例题

**例**：已知全集 $U = \{1,2,3,4,5\}$，$A = \{1,2,3\}$，$B = \{2,3,4\}$，求：

(1) $A \cap B$  
(2) $A \cup B$  
(3) $\complement_U A$  
(4) $\complement_U (A \cap B)$

> [!details]- 解答
> (1) $A \cap B = \{2,3\}$  
> (2) $A \cup B = \{1,2,3,4\}$  
> (3) $\complement_U A = \{4,5\}$  
> (4) $A \cap B = \{2,3\}$，$\complement_U (A \cap B) = \{1,4,5\}$

## 易错提醒

> [!warning]
> 1. 补集运算**必须指明全集 $U$**，否则 $\complement A$ 无意义
> 2. $A \cap B = \varnothing$ 不代表 $A$ 与 $B$ 没有关系，只是无公共元素
> 3. 德·摩根律在解含补集的方程时非常有用，但常被忽略
