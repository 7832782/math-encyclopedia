## 反证法

### 基本思想

**原理**：通过证明命题的否定为假，从而证明原命题为真。

**逻辑基础**：排中律——$p$ 与 $\neg p$ 必有一真一假。

### 步骤

1. 假设结论不成立（假设结论的否定成立）
2. 从假设出发，推出矛盾（与已知条件矛盾，或与公理、定理矛盾）
3. 否定假设，肯定原结论

### 适用情况

| 适合使用反证法的情形               | 示例                        |
| ---------------------------------- | --------------------------- |
| 结论以否定形式出现                 | 证明"$\sqrt{2}$ 不是有理数" |
| 结论以"至少""至多""唯一"等形式出现 | 证明"方程至少有一个实根"    |
| 直接证明困难                       | 证明"素数有无穷多个"        |
| 结论的反面更明确                   | 证明"$a \neq b$"            |

### 典型例题

**例 1**：证明 $\sqrt{2}$ 是无理数

> 假设 $\sqrt{2}$ 是有理数，则 $\sqrt{2} = \dfrac{p}{q}$（$p, q$ 为正整数且互质）
>
> 两边平方：$2 = \dfrac{p^2}{q^2}$，即 $p^2 = 2q^2$
>
> $\therefore p^2$ 是偶数，$\therefore p$ 是偶数
>
> 设 $p = 2k$，则 $4k^2 = 2q^2$，即 $q^2 = 2k^2$
>
> $\therefore q^2$ 是偶数，$\therefore q$ 是偶数
>
> 这与 $p, q$ 互质矛盾
>
> $\therefore \sqrt{2}$ 是无理数

**例 2**：证明 $a, b, c$ 中至少有一个不小于 $\dfrac{a+b+c}{3}$

> 假设 $a, b, c$ 都小于 $\dfrac{a+b+c}{3}$
>
> 则 $a + b + c < 3 \cdot \dfrac{a+b+c}{3} = a + b + c$
>
> 矛盾
>
> $\therefore a, b, c$ 中至少有一个不小于 $\dfrac{a+b+c}{3}$

**例 3**：证明方程 $x^3 + x + 1 = 0$ 在 $\mathbb{R}$ 上有且只有一个实根

> 设 $f(x) = x^3 + x + 1$
>
> **存在性**：$f(-1) = -1 < 0$，$f(0) = 1 > 0$
>
> 由零点存在性定理，$f(x)$ 在 $(-1, 0)$ 内有零点
>
> **唯一性**（反证法）：
>
> 假设方程有两个不同的实根 $x_1 \neq x_2$
>
> 由罗尔定理，$\exists \xi \in (x_1, x_2)$，使 $f'(\xi) = 0$
>
> 但 $f'(x) = 3x^2 + 1 \geq 1 > 0$，矛盾
>
> $\therefore$ 方程有且只有一个实根

## 穷举法

### 基本思想

**原理**：当问题的可能情况有限时，逐一验证所有情况。

**逻辑基础**：分类讨论要"不重不漏"。

### 步骤

1. 分析问题的所有可能情况
2. 对每种情况分别验证或求解
3. 综合所有情况得出结论

### 典型例题

**例 1**：证明任意三个整数中，至少有两个整数的差是偶数

> 设三个整数为 $a, b, c$
>
> 整数按奇偶性分为两类：奇数、偶数
>
> 由抽屉原理，三个整数中至少有两个同奇或同偶
>
> 同奇的两数之差为偶数，同偶的两数之差为偶数
>
> $\therefore$ 至少有两个整数的差是偶数

**例 2**：证明 $|x| + |y| \geq |x+y|$（$x, y \in \mathbb{R}$）

> 按 $x, y$ 的符号分类：
>
> (1) $x \geq 0, y \geq 0$：$|x| + |y| = x + y = |x+y|$
>
> (2) $x \geq 0, y < 0$：$|x| + |y| = x - y \geq |x+y|$
>
> (3) $x < 0, y \geq 0$：$|x| + |y| = -x + y \geq |x+y|$
>
> (4) $x < 0, y < 0$：$|x| + |y| = -x - y = |x+y|$
>
> 综上，$|x| + |y| \geq |x+y|$

## 反证法与穷举法的选择

| 特征                   | 推荐方法 |
| ---------------------- | -------- |
| 结论的反面更明确       | 反证法   |
| 结论以否定形式出现     | 反证法   |
| 可能情况有限且易于枚举 | 穷举法   |
| 需要分类讨论参数       | 穷举法   |

## 综合应用

**例**：证明质数有无穷多个

> （欧几里得证明，反证法）
>
> 假设质数有限，设为 $p_1, p_2, \ldots, p_n$
>
> 构造 $N = p_1 p_2 \cdots p_n + 1$
>
> $N$ 除以任何 $p_i$ 都余 1，不被任何质数整除
>
> 但 $N > 1$ 必有质因数，矛盾
>
> $\therefore$ 质数有无穷多个
