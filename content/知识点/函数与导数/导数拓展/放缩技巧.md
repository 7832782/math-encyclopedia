## $e^x$ 系列放缩

| 放缩式 | 取等条件 | 级别 |
|--------|---------|------|
| $e^x \geq x + 1$ | $x = 0$ | 必须掌握 |
| $e^x \geq ex$ | $x = 1$ | 必须掌握 |
| $e^x \geq \dfrac{e^2}{4}x^2 > x^2 \;(x > 0)$ | $x = 2$ | 稍微了解 |
| $e^x \geq \dfrac{1}{2}x^3 \;(x > 0)$ | — | 稍微了解 |
| $e^x > x$ | — | 必须掌握 |
| $e^x \leq \dfrac{1}{1-x} \;(x < 1)$ | — | 稍微了解 |
| $e^x \geq \sqrt{e(x + \dfrac{1}{2})}$ | — | 扩展 |

> [!tip] 核心记忆：**$e^x \geq x + 1$**，通过代换 $x \to x-1$, $x \to -x$ 等可推出大部分形式

## $\ln x$ 系列放缩

| 放缩式 | 取等条件 | 级别 |
|--------|---------|------|
| $\ln x \leq x - 1$ | $x = 1$ | 必须掌握 |
| $\ln x < x$ | — | 必须掌握 |
| $\ln(1 + x) \leq x \;(x > -1)$ | $x = 0$ | 必须掌握 |
| $\ln x \leq \dfrac{x}{e}$ | $x = e$ | 稍微了解 |
| $\ln x \geq 1 - \dfrac{1}{x}$ | $x = 1$ | 必须掌握 |
| $\dfrac{x}{1+x} \leq \ln(1+x) \leq x$ | $x = 0$ | 稍微了解 |

> [!tip] 核心记忆：**$\ln x \leq x - 1$**，对数线在 $y=x-1$ 下方

## 使用步骤

1. 判断要证明的不等式方向
2. 选择合适的放缩式
3. 验证取等条件是否在定义域内
4. 放缩后求和/求最值
