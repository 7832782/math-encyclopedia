## 定义

对于函数 $f(x)$，若存在一个**非零常数** $T$，使得对定义域内的**任意** $x$，都有

$$f(x + T) = f(x)$$

则称 $f(x)$ 为**周期函数**，$T$ 是它的一个**周期**。

若所有正周期中存在一个最小的正数，则称该最小正数为**最小正周期**（通常简称周期）。

## 常见周期结论

| 条件 | 周期 |
|------|------|
| $f(x + a) = -f(x)$ | $T = 2a$ |
| $f(x + a) = \dfrac{1}{f(x)}$ | $T = 2a$ |
| $f(x + a) = -\dfrac{1}{f(x)}$ | $T = 2a$ |
| $f(x + a) = \dfrac{1 + f(x)}{1 - f(x)}$ | $T = 2a$ |
| $f(x + a) = f(x - a)$ | $T = 2a$ |
| $f(x + a) = \dfrac{f(x) + 1}{f(x) - 1}$ | $T = 4a$ |

> [!tip] 记忆方法
> 凡是出现 $f(x+a)$ 与 $f(x)$ 之间带符号或取倒数的关系，周期通常为 $2a$

## 常用函数的周期

| 函数 | 最小正周期 |
|------|-----------|
| $\sin x$ | $2\pi$ |
| $\cos x$ | $2\pi$ |
| $\tan x$ | $\pi$ |
| $\sin(ax + b)$ | $\dfrac{2\pi}{\|a\|}$ |
| $\cos(ax + b)$ | $\dfrac{2\pi}{\|a\|}$ |
| $\tan(ax + b)$ | $\dfrac{\pi}{\|a\|}$ |

## 典型例题

**例**：已知 $f(x+2) = -f(x)$，求证 $f(x)$ 是周期函数并求周期

> [!details]- 解答
> $f(x+4) = f((x+2)+2) = -f(x+2) = -(-f(x)) = f(x)$  
> 所以 $f(x)$ 以 $4$ 为周期。

## 易错提醒

> [!warning]
> 1. 周期函数一定有无数个周期（$\pm T, \pm 2T, \pm 3T, \dots$）
> 2. 注意周期与对称性的区别：$f(x+a)=f(x)$ 是周期，$f(a+x)=f(a-x)$ 是对称
> 3. 有些函数有周期但没有最小正周期（如常数函数 $f(x)=c$）
