## 核心思想

已知多项式 $P(x)$ 的一个根 $x = a$，则 $(x-a)$ 是 $P(x)$ 的因式。用长除法可以得到因式分解结果。

## 步骤

以 $2x^3 - 7x^2 + 2x + 3$ 为例，已知 $x = 1$ 是根：

1. 写除式 $x - 1$ 和被除式 $2x^3 - 7x^2 + 2x + 3$
2. 逐项除：首项 $2x^3 \div x = 2x^2$，写商
3. 回乘：$2x^2(x-1) = 2x^3 - 2x^2$，相减
4. 重复直到余数为 0

过程：
```
      2x² - 5x - 3
      ─────────────
x - 1 ) 2x³ - 7x² + 2x + 3
       2x³ - 2x²
       ─────────
           -5x² + 2x
           -5x² + 5x
           ─────────
                -3x + 3
                -3x + 3
                ───────
                     0
```

$$2x^3 - 7x^2 + 2x + 3 = (x - 1)(2x^2 - 5x - 3)$$

再因式分解 $2x^2 - 5x - 3 = (x-3)(2x+1)$（十字相乘法）

$$\therefore \text{原式} = (x-1)(x-3)(2x+1)$$

## 适用场景

- 已知一个有理根（通过有理根定理试探）
- 三次及以上多项式因式分解
- 求高次方程的全部根
