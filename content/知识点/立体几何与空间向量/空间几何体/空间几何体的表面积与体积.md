## 体积公式

| 几何体 | 体积公式 |
|--------|---------|
| 柱体 | $V = Sh$ |
| 锥体 | $V = \dfrac{1}{3}Sh$ |
| 台体 | $V = \dfrac{1}{3}(S' + \sqrt{S'S} + S)h$ |
| 球体 | $V = \dfrac{4}{3}\pi R^3$ |

## 表面积公式

| 几何体 | 表面积公式 |
|--------|---------|
| 圆柱 | $S = 2\pi r^2 + 2\pi rl$ |
| 圆锥 | $S = \pi r^2 + \pi rl$ |
| 圆台 | $S = \pi(r^2 + r'^2 + rl + r'l)$ |
| 球 | $S = 4\pi R^2$ |

## 典型例题

**例**：球的体积为 $36\pi$，求表面积

> $V = \dfrac{4}{3}\pi R^3 = 36\pi \Rightarrow R^3 = 27 \Rightarrow R = 3$  
> $S = 4\pi R^2 = 36\pi$
