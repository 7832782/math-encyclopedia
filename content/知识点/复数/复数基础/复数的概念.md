## 定义

形如 $z = a + bi$（$a, b \in \mathbb{R}$）的数称为**复数**。

- $a$：**实部**，记作 $\operatorname{Re}(z)$
- $b$：**虚部**，记作 $\operatorname{Im}(z)$
- $i$：**虚数单位**，$i^2 = -1$

## 复数的分类

$$z = a + bi \begin{cases} b = 0 & \text{实数} \\ b \neq 0 & \text{虚数} \begin{cases} a = 0 & \text{纯虚数} \\ a \neq 0 & \text{非纯虚数} \end{cases} \end{cases}$$

## 共轭复数

$\bar{z} = a - bi$ 是 $z = a + bi$ 的**共轭复数**。

## 复数相等

$$a + bi = c + di \iff a = c \text{ 且 } b = d$$

## 典型例题

**例**：$z = 3 - 2i$，求实部、虚部、共轭复数、模

> $\operatorname{Re}(z) = 3$，$\operatorname{Im}(z) = -2$  
> $\bar{z} = 3 + 2i$，$|z| = \sqrt{3^2 + (-2)^2} = \sqrt{13}$
