## 运算法则

设 $z_1 = a + bi$，$z_2 = c + di$：

| 运算 | 公式 |
|:----|:-----|
| **加法** | $(a+bi) + (c+di) = (a+c) + (b+d)i$ |
| **减法** | $(a+bi) - (c+di) = (a-c) + (b-d)i$ |
| **乘法** | $(a+bi)(c+di) = (ac-bd) + (ad+bc)i$ |
| **除法** | $\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{(c+di)(c-di)} = \dfrac{ac+bd}{c^2+d^2} + \dfrac{bc-ad}{c^2+d^2}i$ |

> [!tip] 复数的运算像多项式，记得 $i^2 = -1$ 即可

## 除法步骤

1. 分子分母同乘分母的共轭
2. 利用 $(c+di)(c-di) = c^2 + d^2$ 使分母实数化
3. 化简

## 典型例题

**例**：计算 $\dfrac{1+2i}{3-4i}$

> 分子分母同乘 $3+4i$：  
> $\dfrac{(1+2i)(3+4i)}{(3-4i)(3+4i)} = \dfrac{3+4i+6i+8i^2}{9+16} = \dfrac{-5+10i}{25} = -\dfrac{1}{5} + \dfrac{2}{5}i$

## 易错提醒

> [!warning]
> 1. $i^2 = -1$，不是 $1$！
> 2. 复数的除法必须通过共轭将分母实数化
