## 基本思想

**原理**：将不等式的一边适当放大或缩小，转化为容易证明的形式。

$$A < B < C \Rightarrow A < C$$

**关键**：放缩要"适度"，既要能证明结论，又不能放缩过头。

## 常见放缩技巧

### 1. 舍项放缩

**例**：证明 $\dfrac{1}{n+1} < \ln\left(1+\dfrac{1}{n}\right) < \dfrac{1}{n}$（$n \in \mathbb{N}^*$）

> $\ln\left(1+\dfrac{1}{n}\right) = \ln\frac{n+1}{n} = \int_1^{1+\dfrac{1}{n}} \dfrac{1}{x}dx$
>
> 由于 $\dfrac{1}{x}$ 在 $(0, +\infty)$ 上递减：
>
> $\dfrac{1}{1+\dfrac{1}{n}} \cdot \dfrac{1}{n} < \ln\left(1+\dfrac{1}{n}\right) < \dfrac{1}{n}$
>
> 即 $\dfrac{1}{n+1} < \ln\left(1+\dfrac{1}{n}\right) < \dfrac{1}{n}$

### 2. 利用基本不等式放缩

**例**：已知 $n \in \mathbb{N}^*$，证明 $1 + \dfrac{1}{\sqrt{2}} + \dfrac{1}{\sqrt{3}} + \cdots + \dfrac{1}{\sqrt{n}} < 2\sqrt{n}$

> $\dfrac{1}{\sqrt{k}} = \dfrac{2}{2\sqrt{k}} = \dfrac{2}{\sqrt{k} + \sqrt{k}} < \dfrac{2}{\sqrt{k} + \sqrt{k-1}} = 2(\sqrt{k} - \sqrt{k-1})$
>
> $\therefore \sum_{k=1}^{n} \dfrac{1}{\sqrt{k}} < \sum_{k=1}^{n} 2(\sqrt{k} - \sqrt{k-1}) = 2\sqrt{n}$

### 3. 分式放缩

**例**：证明 $\dfrac{1}{2} < \dfrac{1}{n+1} + \dfrac{1}{n+2} + \cdots + \dfrac{1}{2n} < 1$（$n \in \mathbb{N}^*$）

> 每项用最大值、最小值替换：
>
> 下界：$\dfrac{1}{2n} + \dfrac{1}{2n} + \cdots + \dfrac{1}{2n} = n \cdot \dfrac{1}{2n} = \dfrac{1}{2}$（不取等）
>
> 上界：$\dfrac{1}{n+1} + \dfrac{1}{n+1} + \cdots + \dfrac{1}{n+1} = n \cdot \dfrac{1}{n+1} < 1$
>
> $\therefore \dfrac{1}{2} < \sum_{k=1}^{n} \dfrac{1}{n+k} < 1$

### 4. 利用函数单调性放缩

**例**：证明 $e^x > 1 + x$（$x \neq 0$）

> 令 $f(x) = e^x - 1 - x$
>
> $f'(x) = e^x - 1$
>
> 当 $x > 0$ 时，$f'(x) > 0$，$f(x) > f(0) = 0$
>
> 当 $x < 0$ 时，$f'(x) < 0$，$f(x) > f(0) = 0$
>
> $\therefore e^x > 1 + x$（$x \neq 0$）

## 数列求和中的放缩

**例**：证明 $1 + \dfrac{1}{2^2} + \dfrac{1}{3^2} + \cdots + \dfrac{1}{n^2} < 2$（$n \in \mathbb{N}^*$）

> $\dfrac{1}{k^2} < \dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$（$k \geq 2$）
>
> $\therefore \sum_{k=1}^{n} \dfrac{1}{k^2} = 1 + \sum_{k=2}^{n} \dfrac{1}{k^2}$
>
> $< 1 + \sum_{k=2}^{n} \left(\dfrac{1}{k-1} - \dfrac{1}{k}\right)$
>
> $= 1 + \left(1 - \dfrac{1}{2}\right) + \left(\dfrac{1}{2} - \dfrac{1}{3}\right) + \cdots + \left(\dfrac{1}{n-1} - \dfrac{1}{n}\right)$
>
> $= 1 + 1 - \dfrac{1}{n} < 2$

## 放缩的原则

1. **方向正确**：放大后的值要大于原值，缩小后的值要小于原值
2. **适度放缩**：不能放缩过头，否则无法证明结论
3. **尽量精确**：放缩后的式子应尽量接近原式

## 典型例题

**例**：已知 $n \in \mathbb{N}^*$，证明 $(1+1)(1+\dfrac{1}{4})\cdots(1+\dfrac{1}{n^2}) < 2$

> 分析：$1 + \dfrac{1}{k^2} = \dfrac{k^2+1}{k^2} < \dfrac{k^2+k}{k^2} = \dfrac{k+1}{k}$（放缩）
>
> $\therefore \prod_{k=1}^{n} \left(1+\dfrac{1}{k^2}\right) < \prod_{k=1}^{n} \dfrac{k+1}{k}$
>
> $= \dfrac{2}{1} \cdot \dfrac{3}{2} \cdot \dfrac{4}{3} \cdots \dfrac{n+1}{n} = n+1$
>
> 这样放缩过头了！换一种方法：
>
> $1 + \dfrac{1}{k^2} < 1 + \dfrac{1}{k(k-1)} = \dfrac{k^2-k+1}{k(k-1)}$（$k \geq 2$）
>
> 仍不够，尝试另一种放缩：
>
> 利用 $\ln(1+x) < x$，有 $\ln(1+\dfrac{1}{k^2}) < \dfrac{1}{k^2}$
>
> $\ln\left[\prod_{k=1}^{n}(1+\dfrac{1}{k^2})\right] = \sum_{k=1}^{n}\ln(1+\dfrac{1}{k^2}) < \sum_{k=1}^{n}\dfrac{1}{k^2}$
>
> 由前面的结论，$\sum_{k=1}^{n}\dfrac{1}{k^2} < 2$
>
> $\therefore \prod_{k=1}^{n}(1+\dfrac{1}{k^2}) < e^2$
>
> 这仍然不够精确。实际可用更精细的放缩证明。
