## 综合法

**特点**：从已知条件出发，利用定义、定理、性质，逐步推出结论。

**思维方向**：条件 $\Rightarrow$ 结论（顺推）

**格式**：

```
因为 ...（已知条件）
所以 ...（根据某定理）
又因为 ...
所以 ...（结论）
```

**例 1**：已知 $a, b > 0$，证明 $a + \dfrac{1}{a} \geq 2$

> 由基本不等式，对于 $a > 0$，有：
>
> $a + \dfrac{1}{a} \geq 2\sqrt{a \cdot \dfrac{1}{a}} = 2$
>
> 当 $a = \dfrac{1}{a}$ 即 $a = 1$ 时取等号
>
> $\therefore a + \dfrac{1}{a} \geq 2$

**例 2**：已知 $a, b, c > 0$，证明 $(a+b)(b+c)(c+a) \geq 8abc$

> 由基本不等式：
>
> - $a + b \geq 2\sqrt{ab}$
> - $b + c \geq 2\sqrt{bc}$
> - $c + a \geq 2\sqrt{ca}$
>
> 三式相乘：
>
> $(a+b)(b+c)(c+a) \geq 8\sqrt{a^2b^2c^2} = 8abc$

## 分析法

**特点**：从结论出发，逆向寻找结论成立的充分条件，直到找到已知条件。

**思维方向**：结论 $\Leftarrow$ 条件（逆推）

**格式**：

```
要证明 ...（结论）
只需证明 ...（充分条件）
又只需证明 ...
而已知 ...（找到条件）
所以原不等式成立
```

**例**：证明 $\sqrt{3} + \sqrt{5} < 4$

> 要证明 $\sqrt{3} + \sqrt{5} < 4$
>
> 只需证明 $(\sqrt{3} + \sqrt{5})^2 < 16$（两边同正）
>
> 即 $3 + 5 + 2\sqrt{15} < 16$
>
> 即 $\sqrt{15} < 4$
>
> 只需证明 $15 < 16$（两边平方）
>
> 此式显然成立
>
> $\therefore \sqrt{3} + \sqrt{5} < 4$

## 分析综合法

**特点**：结合分析法与综合法，两头凑。

**适用情况**：条件与结论距离较远，单向推导困难。

**例**：已知 $a > b > 0$，证明 $\dfrac{a^2}{b} + \dfrac{b^2}{a} > a + b$

> **分析法**：要证明 $\dfrac{a^2}{b} + \dfrac{b^2}{a} > a + b$
>
> 只需证明 $\dfrac{a^3 + b^3}{ab} > a + b$
>
> 只需证明 $a^3 + b^3 > ab(a+b)$
>
> 只需证明 $(a+b)(a^2-ab+b^2) > ab(a+b)$
>
> **综合法**：$\because a > b > 0$，$\therefore a + b > 0$
>
> 两边约去 $a+b$，只需证明 $a^2 - ab + b^2 > ab$
>
> 即 $a^2 - 2ab + b^2 > 0$，即 $(a-b)^2 > 0$
>
> $\because a > b$，$\therefore (a-b)^2 > 0$ 成立
>
> $\therefore$ 原不等式成立

## 选择方法的原则

| 特征                       | 推荐方法   |
| -------------------------- | ---------- |
| 条件充分，结论直接         | 综合法     |
| 结论形式复杂，难以直接入手 | 分析法     |
| 条件与结论距离较远         | 分析综合法 |
| 不等式两边同号             | 作商比较法 |
| 多项式形式                 | 作差比较法 |

## 典型例题

**例**：已知 $a, b, c$ 为正数，证明 $\dfrac{a^2}{b} + \dfrac{b^2}{c} + \dfrac{c^2}{a} \geq a + b + c$

> **分析**：形式对称，考虑用排序不等式或柯西不等式
>
> 但高中范围内，可用基本不等式：
>
> $\dfrac{a^2}{b} + b \geq 2\sqrt{\dfrac{a^2}{b} \cdot b} = 2a$
>
> 同理：$\dfrac{b^2}{c} + c \geq 2b$，$\dfrac{c^2}{a} + a \geq 2c$
>
> 三式相加：$\dfrac{a^2}{b} + \dfrac{b^2}{c} + \dfrac{c^2}{a} + a + b + c \geq 2a + 2b + 2c$
>
> $\therefore \dfrac{a^2}{b} + \dfrac{b^2}{c} + \dfrac{c^2}{a} \geq a + b + c$
