## 定义

**柯西不等式**（Cauchy-Schwarz Inequality）是数学中最基础的不等式之一，有代数形式、向量形式、积分形式等多种等价的表述方式。

### 代数形式（二维）

$$(a_1^2 + a_2^2)(b_1^2 + b_2^2) \geq (a_1b_1 + a_2b_2)^2$$

等号成立当且仅当 $\dfrac{a_1}{b_1} = \dfrac{a_2}{b_2}$（规定分母为 $0$ 时分子也为 $0$）。

### 代数形式（n 维推广）

$$(a_1^2 + a_2^2 + \cdots + a_n^2)(b_1^2 + b_2^2 + \cdots + b_n^2) \geq (a_1b_1 + a_2b_2 + \cdots + a_nb_n)^2$$

即：

$$\left(\sum_{i=1}^{n}a_i^2\right)\left(\sum_{i=1}^{n}b_i^2\right) \geq \left(\sum_{i=1}^{n}a_i b_i\right)^2$$

### 向量形式

$$|\vec{a} \cdot \vec{b}| \leq |\vec{a}| \cdot |\vec{b}|$$

即两向量内积的绝对值不超过模长的乘积。

### 三角形式

$$\sqrt{a_1^2 + a_2^2} + \sqrt{b_1^2 + b_2^2} \geq \sqrt{(a_1+b_1)^2 + (a_2+b_2)^2}$$

## 证明思路（构造二次函数法）

构造关于 $x$ 的二次函数：

$$f(x) = \sum_{i=1}^{n}(a_i x - b_i)^2 = \left(\sum a_i^2\right)x^2 - 2\left(\sum a_i b_i\right)x + \left(\sum b_i^2\right) \geq 0$$

判别式 $\Delta \leq 0$：

$$\Delta = 4\left(\sum a_i b_i\right)^2 - 4\left(\sum a_i^2\right)\left(\sum b_i^2\right) \leq 0$$

整理即得柯西不等式。

## 常用推论

### 柯西不等式的变形

$$\sum \frac{a_i^2}{b_i} \geq \dfrac{(\sum a_i)^2}{\sum b_i} \quad (b_i > 0)$$

### 权方和不等式

$$\dfrac{a_1^2}{b_1} + \dfrac{a_2^2}{b_2} + \cdots + \dfrac{a_n^2}{b_n} \geq \dfrac{(a_1 + a_2 + \cdots + a_n)^2}{b_1 + b_2 + \cdots + b_n}$$

## 典型例题

**例**：已知 $x + 2y = 6$，求 $x^2 + y^2$ 的最小值。

> [!details]- 解答
> 由柯西不等式：
> $$(1^2 + 2^2)(x^2 + y^2) \geq (1\cdot x + 2\cdot y)^2 = 36$$
> $$5(x^2 + y^2) \geq 36$$
> $$x^2 + y^2 \geq \dfrac{36}{5}$$
> 当 $\dfrac{x}{1} = \dfrac{y}{2}$，即 $x = \dfrac{6}{5}, y = \dfrac{12}{5}$ 时取等。
