## 定义

**幂平均**（Power Mean / Generalized Mean）是算术平均、几何平均、调和平均的统一推广。

### 幂平均的定义

对 $n$ 个正数 $x_1, x_2, \ldots, x_n$ 和实数 $r \neq 0$，定义 $r$ 次幂平均：

$$M_r(x_1, x_2, \ldots, x_n) = \left(\dfrac{x_1^r + x_2^r + \cdots + x_n^r}{n}\right)^{\dfrac{1}{r}}$$

### 特殊情形

| $r$ 的取值 | $M_r$ | 名称 |
|:----------:|-------|------|
| $r = 1$ | $\dfrac{x_1 + x_2 + \cdots + x_n}{n}$ | **算术平均** (AM) |
| $r = 0$ | $\sqrt[n]{x_1 x_2 \cdots x_n}$ | **几何平均** (GM)（极限定义） |
| $r = -1$ | $\dfrac{n}{\dfrac{1}{x_1} + \dfrac{1}{x_2} + \cdots + \dfrac{1}{x_n}}$ | **调和平均** (HM) |
| $r = 2$ | $\sqrt{\dfrac{x_1^2 + x_2^2 + \cdots + x_n^2}{n}}$ | **平方平均** (RMS) |

### 幂均不等式

> 幂平均函数 $M_r$ 关于指数 $r$ 单调不减：
> 若 $r < s$，则 $M_r \leq M_s$，等号成立当且仅当 $x_1 = x_2 = \cdots = x_n$。

特别地：

$$M_{-1} \leq M_0 \leq M_1 \leq M_2$$

即：

$$\dfrac{n}{\sum \dfrac{1}{x_i}} \leq \sqrt[n]{\prod x_i} \leq \dfrac{\sum x_i}{n} \leq \sqrt{\dfrac{\sum x_i^2}{n}}$$

**调和平均 ≤ 几何平均 ≤ 算术平均 ≤ 平方平均**

### 证明思路

证明 $M_r \leq M_s$ 的思路：
1. 利用 Hölder 不等式或琴生不等式
2. 构造函数 $g(r) = \ln M_r$，证明其单调性
3. $r = 0$ 的情形通过极限 $\displaystyle\lim_{r \to 0} M_r = \sqrt[n]{\prod x_i}$ 补充

## 典型例题

**例**：比较 $\dfrac{a+b}{2}$、$\sqrt{ab}$、$\sqrt{\dfrac{a^2+b^2}{2}}$ 的大小关系。

> [!details]- 解答
> 由幂均不等式 $M_0 \leq M_1 \leq M_2$：
> $$\sqrt{ab} \leq \dfrac{a+b}{2} \leq \sqrt{\dfrac{a^2+b^2}{2}}$$
> 当 $a = b$ 时等号成立。
