## 定义

**琴生不等式**（Jensen's Inequality）描述了凸函数与凹函数的函数值与自变量加权平均之间的关系。

### 凸函数版本

若 $f(x)$ 是区间 $I$ 上的**凸函数**（下凸，二阶导 $f''(x) \geq 0$），则对任意 $x_1, x_2, \ldots, x_n \in I$ 和 $\lambda_i \geq 0, \sum \lambda_i = 1$：

$$f(\lambda_1 x_1 + \lambda_2 x_2 + \cdots + \lambda_n x_n) \leq \lambda_1 f(x_1) + \lambda_2 f(x_2) + \cdots + \lambda_n f(x_n)$$

### 凹函数版本

若 $f(x)$ 是区间 $I$ 上的**凹函数**（上凸，二阶导 $f''(x) \leq 0$），则不等号反向：

$$f(\lambda_1 x_1 + \lambda_2 x_2 + \cdots + \lambda_n x_n) \geq \lambda_1 f(x_1) + \lambda_2 f(x_2) + \cdots + \lambda_n f(x_n)$$

### 二元形式（最常见）

$$\begin{aligned}
\text{凸函数：}&\quad f\left(\dfrac{x+y}{2}\right) \leq \dfrac{f(x)+f(y)}{2} \\[4pt]
\text{凹函数：}&\quad f\left(\dfrac{x+y}{2}\right) \geq \dfrac{f(x)+f(y)}{2}
\end{aligned}$$

## 常见凸函数与凹函数

| 函数 | 区间 | 凹凸性 |
|------|------|--------|
| $y = x^2$ | $\mathbb{R}$ | 凸（下凸） |
| $y = e^x$ | $\mathbb{R}$ | 凸 |
| $y = \ln x$ | $(0, +\infty)$ | 凹（上凸） |
| $y = x\ln x$ | $(0, +\infty)$ | 凸 |
| $y = \sqrt{x}$ | $[0, +\infty)$ | 凹 |
| $y = \sin x$ | $[0, \pi]$ | 凹 |
| $y = \dfrac{1}{x}$ | $(0, +\infty)$ | 凸 |

## 证明思路（归纳法）

- $n=2$ 时由凸函数定义直接成立
- 假设 $n=k$ 时成立，利用 $n=k$ 的情形证明 $n=k+1$ 成立
- 取 $\lambda_k' = \lambda_k + \lambda_{k+1}$，令 $y = \dfrac{\lambda_k}{\lambda_k + \lambda_{k+1}} x_k + \dfrac{\lambda_{k+1}}{\lambda_k + \lambda_{k+1}} x_{k+1}$ 即可

## 应用示例

### 例 1：用琴生不等式证明均值不等式

取 $f(x) = \ln x$（凹函数）：

$$f\left(\dfrac{x_1 + x_2 + \cdots + x_n}{n}\right) \geq \dfrac{f(x_1) + f(x_2) + \cdots + f(x_n)}{n}$$

$$\ln\left(\dfrac{\sum x_i}{n}\right) \geq \dfrac{\sum \ln x_i}{n} = \ln\left(\sqrt[n]{x_1 x_2 \cdots x_n}\right)$$

即：

$$\dfrac{x_1 + x_2 + \cdots + x_n}{n} \geq \sqrt[n]{x_1 x_2 \cdots x_n}$$

### 例 2：已知 $f(x) = x^2$，求 $f(x) + f(y)$ 的最小值

若 $x + y = 2$，由 $y = x^2$ 是凸函数：

$$f\left(\dfrac{x+y}{2}\right) \leq \dfrac{f(x)+f(y)}{2}$$

$$\dfrac{f(x)+f(y)}{2} \geq f(1) = 1$$

$$f(x) + f(y) \geq 2$$

当 $x = y = 1$ 时取等。
