## 定义

**糖水不等式**描述了一个直观的生活现象：

> 在一杯糖水中加入一些糖，糖水会变得更甜。

数学化表述：设 $b > a > 0$（$b$ 克糖水中有 $a$ 克糖，浓度为 $\dfrac{a}{b}$），再加入 $m > 0$ 克糖，则新浓度为 $\dfrac{a+m}{b+m}$，显然：

$$\dfrac{a}{b} < \dfrac{a+m}{b+m}$$

或者更一般地（真分数加正分子分母后变大）：

> 若 $0 < a < b$，$m > 0$，则 $\dfrac{a}{b} < \dfrac{a+m}{b+m}$。

### 变式

若 $a > b > 0$（假分数），则有反向不等式：

$$\dfrac{a}{b} > \dfrac{a+m}{b+m}$$

## 证明

$$\dfrac{a+m}{b+m} - \dfrac{a}{b} = \dfrac{b(a+m) - a(b+m)}{b(b+m)} = \dfrac{m(b-a)}{b(b+m)} > 0$$

因为 $b - a > 0$，$m > 0$，$b > 0$，故差为正。

## 几何意义

点 $(b, a)$ 和 $(b+m, a+m)$ 在与原点连线上，后者斜率更大（当 $a < b$ 时）：

$$\text{斜率} = \dfrac{a}{b} < \dfrac{a+m}{b+m}$$

即在第一象限内，点沿着 $45^\circ$ 方向向右上方移动时，与原点连线的斜率增大。

## 常见应用

### 判断分数大小

$$\dfrac{3}{7} < \dfrac{4}{8} = \dfrac{1}{2} \quad (\text{取 } m=1)$$
$$\dfrac{5}{9} < \dfrac{6}{10} = \dfrac{3}{5} \quad (\text{取 } m=1)$$

### 不等式链

$$\dfrac{a}{b} < \dfrac{a+c}{b+c} < \dfrac{a+2c}{b+2c} < \cdots < 1$$

即向上"加糖"的次数越多，比值越接近 $1$。

### 解比较大小问题

**例**：比较 $\dfrac{2024}{2025}$ 和 $\dfrac{2025}{2026}$ 的大小。

> [!details]- 解答
> 令 $\dfrac{a}{b} = \dfrac{2024}{2025}$，$m=1$，则：
> $$\dfrac{2024}{2025} = \dfrac{a}{b} < \dfrac{a+m}{b+m} = \dfrac{2025}{2026}$$
> 所以 $\dfrac{2024}{2025} < \dfrac{2025}{2026}$。
