## 基本性质

| 性质    | 内容                                                |
| ----- | ------------------------------------------------- |
| 对称性   | $a > b \iff b < a$                                |
| 传递性   | $a > b, b > c \Rightarrow a > c$                  |
| 加法    | $a > b \Rightarrow a + c > b + c$                 |
| 乘法    | $a > b, c > 0 \Rightarrow ac > bc$                |
| 乘法（负） | $a > b, c < 0 \Rightarrow ac < bc$                |
| 同向相加  | $a > b, c > d \Rightarrow a + c > b + d$          |
| 同向相乘  | $a > b > 0, c > d > 0 \Rightarrow ac > bd$        |
| 可乘方   | $a > b > 0 \Rightarrow a^n > b^n$                 |
| 可开方   | $a > b > 0 \Rightarrow \sqrt[n]{a} > \sqrt[n]{b}$ |

## 比较大小的方法

### 作差法
$a - b > 0 \iff a > b$

### 作商法
$\dfrac{a}{b} > 1 \iff a > b$（$ab > 0$ 时）

## 易错提醒

> [!warning]
> 1. 不等号两边乘负数，方向必须改变
> 2. 同向不等式可以相加但不能相减
> 3. 同向不等式相乘时要求所有数都为正数
