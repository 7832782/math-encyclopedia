## 标准形式

$ax^2 + bx + c > 0$ 或 $ax^2 + bx + c < 0$（$a \neq 0$）

## 解法（图象法）

1. 化二次项系数为**正**
2. 求判别式 $\Delta = b^2 - 4ac$
3. 求根 $x_1, x_2$（若有）
4. "**大于取两边，小于取中间**"

### 具体对照

| $\Delta$ | $ax^2 + bx + c > 0$ | $ax^2 + bx + c < 0$ |
|:---------:|:---:|:---:|
| $\Delta > 0$ | $x < x_1$ 或 $x > x_2$ | $x_1 < x < x_2$ |
| $\Delta = 0$ | $x \neq x_0$ | 无解 |
| $\Delta < 0$ | $x \in \mathbb{R}$ | 无解 |

## 含参讨论

当二次项系数含参数时，需讨论：
1. 系数 $a > 0$、$a = 0$（退化一次）、$a < 0$ 三种情况
2. 根的判别式与大小比较

## 典型例题

**例**：解不等式 $-x^2 + 3x - 2 > 0$

> 两边乘 $-1$：$x^2 - 3x + 2 < 0$  
> $(x-1)(x-2) < 0$  
> 解集：$\{x \mid 1 < x < 2\}$
