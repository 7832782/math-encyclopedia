## 基本性质

$$|a| \geq 0, \quad |a| \geq a, \quad |a| \geq -a$$

$$|ab| = |a||b|, \quad \left|\dfrac{a}{b}\right| = \dfrac{|a|}{|b|}$$

## 三角不等式

$$||a| - |b|| \leq |a \pm b| \leq |a| + |b|$$

**等号成立条件**：

- $|a+b| = |a| + |b|$：$a, b$ 同号或至少一个为零
- $|a-b| = |a| + |b|$：$a, b$ 异号或至少一个为零

## 解法：去绝对值符号

### 方法一：零点分段法

**步骤**：

1. 令绝对值内的式子为 0，求出零点
2. 以零点为界分段讨论
3. 在各段内去掉绝对值符号求解

**例**：解 $|x-2| < 3$

> $-3 < x-2 < 3$
>
> $\therefore -1 < x < 5$

### 方法二：公式法

| 不等式类型     | 解集（$a > 0$）           |
| -------------- | ------------------------- |
| $\|x\| < a$    | $-a < x < a$              |
| $\|x\| > a$    | $x < -a$ 或 $x > a$       |
| $\|x\| \leq a$ | $-a \leq x \leq a$        |
| $\|x\| \geq a$ | $x \leq -a$ 或 $x \geq a$ |

### 方法三：平方法

适用于两边非负的不等式。

**例**：解 $|x+1| < |2x-3|$

> 两边平方：$(x+1)^2 < (2x-3)^2$
>
> 展开：$x^2 + 2x + 1 < 4x^2 - 12x + 9$
>
> 整理：$3x^2 - 14x + 8 > 0$
>
> 解得：$x < \dfrac{2}{3}$ 或 $x > 4$

## 含参讨论

**例**：解关于 $x$ 的不等式 $|x-a| < b$（$a, b \in \mathbb{R}$）

> **情况 1**：$b \leq 0$
>
> - 若 $b < 0$，解集为 $\varnothing$（绝对值非负）
> - 若 $b = 0$，则 $|x-a| < 0$，解集为 $\varnothing$
>
> **情况 2**：$b > 0$
>
> - $-b < x-a < b$
> - $a-b < x < a+b$
>
> **综上**：
>
> - $b \leq 0$ 时，解集为 $\varnothing$
> - $b > 0$ 时，解集为 $(a-b, a+b)$

**例**：解关于 $x$ 的不等式 $|x-2| > a$

> **情况 1**：$a < 0$
>
> - $|x-2| \geq 0 > a$ 恒成立
> - 解集为 $\mathbb{R}$
>
> **情况 2**：$a = 0$
>
> - $|x-2| > 0$
> - 解集为 $x \neq 2$
>
> **情况 3**：$a > 0$
>
> - $x-2 < -a$ 或 $x-2 > a$
> - 解集为 $x < 2-a$ 或 $x > 2+a$
>
> **综上**：
>
> - $a < 0$：$\mathbb{R}$
> - $a = 0$：$x \neq 2$
> - $a > 0$：$(-\infty, 2-a) \cup (2+a, +\infty)$

## 典型例题

**例**：解不等式 $|x-1| + |x+2| \geq 5$

> 零点：$x = 1, x = -2$
>
> **分段讨论**：
>
> (1) $x < -2$：$-(x-1) - (x+2) \geq 5$
>
> $\Rightarrow -2x - 1 \geq 5 \Rightarrow x \leq -3$
>
> 结合 $x < -2$，得 $x \leq -3$
>
> (2) $-2 \leq x \leq 1$：$-(x-1) + (x+2) \geq 5$
>
> $\Rightarrow 3 \geq 5$，无解
>
> (3) $x > 1$：$(x-1) + (x+2) \geq 5$
>
> $\Rightarrow 2x + 1 \geq 5 \Rightarrow x \geq 2$
>
> 结合 $x > 1$，得 $x \geq 2$
>
> **综上**：解集为 $(-\infty, -3] \cup [2, +\infty)$
