今天来介绍高中数学的一个"流氓"解题方法。为什么说它很流氓？大家看下去就懂了。

---

## 从一道"太简单"的题说起

**例**：$a + b = 2$，则 $a^2 + b^2 + 2ab = ?$

太简单了——完全平方公式，$(a+b)^2 = 4$。

但假如你没学过完全平方公式，会怎么想？$a + b = 2$ 但 $a$、$b$ 两个未知数都求不出来——满足条件的 $ab$ 有无数组：$a=1,b=1$；$a=2,b=0$；$a=3,b=-1$……但无论带哪一组进去，结果都等于 $4$。

**这就是核心思想：如果方程数量小于未知数数量，但答案却是确定值——找一组特殊解直接算。**

## 代数题：方程不够，特解来凑

### 对数题

已知 $\log_a c = \dfrac{3}{4}$，$\log_{ab} c = \dfrac{3}{5}$，求 $\log_b c$。

标准做法是换底公式，三四个步骤。但换一个思路：三个未知数 $a,b,c$，只有两个方程，说明 $a,b,c$ 求不出来，但答案一定是定值。

那直接令 $a = 10^4$，$c = 10^3$（这样 $\log_a c = \dfrac{3}{4}$ 成立），再由第二个条件得 $ab = 10^5$，所以 $b = 10$。最后 $\log_{10} 10^3 = 3$，答案秒出。

### 三角题

已知 $\sin(2\alpha + \beta) = 3\sin\beta$，求 $\dfrac{1}{\tan\alpha} - \dfrac{1}{\tan\beta} = k \cdot \tan\alpha$ 中的 $k$。

两个未知数 $\alpha,\beta$，只有一个条件——求不出来，但 $k$ 一定是定值。直接令 $\alpha = \dfrac{\pi}{4}$：

$$\sin(\dfrac{\pi}{2} + \beta) = 3\sin\beta \;\Rightarrow\; \cos\beta = 3\sin\beta \;\Rightarrow\; \tan\beta = \dfrac{1}{3}$$

代入得 $\dfrac{1}{1} - \dfrac{1}{1/3} = k \cdot 1$，$k = -2$，秒杀。

> 当然你也可以令 $\alpha = \dfrac{\pi}{6}$ 去算，结果一样——但我们当然选更简单的那组。

### 高考压轴题

2020 年全国卷理科第 12 题：

已知 $2^a + \log_2 a = 4^b + 2\log_4 b$，比较 $a$ 与 $2b$、$a$ 与 $b^2$ 的关系。

只有一个等式，两个未知数 $a,b$。直接令 $b=1$，右边 $= 4$。尝试 $a=2$ 时左边 $=5 > 4$，说明 $a$ 要小于 $2$，所以 $a < 2b$。再令 $b=2$，右边 $=17$，$a=4$ 时左边 $=18 > 17$，说明 $a < 4$。两轮就能排除两个选项。

这就是"流氓"之处——不需要构造函数的复杂操作，带几组特殊值就能排除出一半选项。

## 几何题：自由度不够，图形来特化

不仅代数题可以这样，几何题也一样。关键在于理解**自由度**。

| 图形 | 自由度 | 说明 |
|------|:-----:|------|
| 三角形 | 3 | 边边角、边角边……需要三个条件 |
| 直角三角形 | 2 | 一个直角已知，还需两个条件 |
| 等边三角形 | 1 | 只有大小（边长）自由 |
| 平行四边形 | 3 | 两边 + 一角 |
| 矩形 | 2 | 长和宽 |
| 正方形 | 1 | 只有边长自由 |
| 长方体 | 3 | 长、宽、高 |
| 正方体 | 1 | 只有棱长自由 |

**原理**：当题目条件给的自由度不够（图形未被确定），但答案却是确定的长度或角度时，我们可以把图形特殊化成更标准的形式来算。

### 平行四边形求数量积

平行四边形 $ABCD$ 中，$AB = 3$，$AP \perp BD$，求 $\overrightarrow{AB} \cdot \overrightarrow{AC}$。

平行四边形需要 3 个条件，但这里只给了 1 个长度——图形是完全自由的。既然自由，不妨让它变成**正方形**。

在正方形中，对角线本身就垂直，所以 $P$ 点与对角线交点 $O$ 重合。$|\overrightarrow{AB}| = 3$，$|\overrightarrow{AC}| = 6$，夹角 $0^\circ$，答案 $3 \times 6 = 18$。

### 动点问题

$\triangle ABC$ 中，$D$ 是 $BC$ **上任意一点**，$M$ 是 $AD$ 中点。若 $\overrightarrow{BM} = \lambda \overrightarrow{AB} + \mu \overrightarrow{AC}$，求 $\lambda + \mu$。

$D$ 是任意一点，那让 $D$ 与 $B$ 重合——$M$ 就是 $AB$ 中点，$\overrightarrow{BM} = -\dfrac{1}{2}\overrightarrow{AB}$，所以 $\lambda = -\dfrac{1}{2}$，$\mu = 0$，$\lambda + \mu = -\dfrac{1}{2}$。

秒杀。

## 总结

当题目出现以下特征时，就可以用"流氓"方法：

**代数**：方程（等式）数量 < 未知数数量，但答案是确定值 → 找一组特殊解代入
**几何**：图形的自由度未被锁死（条件不够），但答案是定值 → 把图形特化成更标准的形式（正方形、等边三角形、正方体……）
**动点**：动点位置自由，但答案是定值 → 把动点放在端点或中点等特殊位置

> 当然，我**不鼓励只靠投机取巧**。这些基本功——换底公式、三角恒等变换、向量展开——你都得会。但在这个基础上掌握这个方法，考试中能省去大量时间。
