## 传统方法的繁琐

解一元二次方程 $ax^2 + bx + c = 0$，我们有四种方法：

| 方法 | 缺点 |
|------|------|
| 直接开平方法 | 局限很大，很多方程不适用 |
| 配方法 | 需先确保二次项系数为 1，再凑完全平方式 |
| 公式法 | 需要记忆公式，计算容易出错，还要判断 $\Delta$ |
| 因式分解法 | 有时很难分解，十字相乘法费时费力 |

有没有更简单的办法？有。2019 年，卡内基梅隆大学华裔数学教授**罗博深**（Po-Shen Loh）提出了一种新解法。

## 核心思路

这个方法只需要韦达定理，没有任何复杂的代数变形。

以 $x^2 - 8x + 12 = 0$ 为例：

由韦达定理：
$$x_1 + x_2 = 8,\quad x_1x_2 = 12$$

设两根分别为 $x_1 = 4 + u$，$x_2 = 4 - u$（以平均值 $\dfrac{8}{2}=4$ 对称分布）

$$(4+u)(4-u) = 16 - u^2 = 12 \;\Rightarrow\; u^2 = 4 \;\Rightarrow\; u = \pm 2$$

$$x_1 = 6,\quad x_2 = 2$$

**三步走**：
1. 求两根平均值 $m = -\dfrac{b}{2a}$（即两根之和的一半）
2. 设两根为 $m \pm u$，由乘积求出 $u$
3. 得两根

## 通用公式

对于 $ax^2 + bx + c = 0$（$a \neq 0$），两根之和为 $-\dfrac{b}{a}$：

$$m = -\dfrac{b}{2a},\quad (m+u)(m-u) = m^2 - u^2 = \dfrac{c}{a}$$

$$u = \sqrt{m^2 - \dfrac{c}{a}}$$

$$x = -\dfrac{b}{2a} \pm \sqrt{\dfrac{b^2}{4a^2} - \dfrac{c}{a}} = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

> 得到的最终结果确实就是求根公式——但思维过程完全不同，直观且不会出错。

## 为什么这个方法好？

- **直观**：从韦达定理出发，自然的对称思维
- **省步骤**：没有配方操作，没有分式运算
- **难出错**：每一步含义清晰，可以随时检验
